= Windows推奨環境でLinuxを使うという迷惑

大前提として、推奨に則ってないこちらに問題があるので、大きな声で _「Windows推奨が悪い」_ とか言わないようにしましょう。

= 実際使えるのか?

_「使える」_

まあ困ることは多いけれど。

実際に困った実例としてはofficeくらい。

- 例えば提出が`.pptx`だとか`.xlsx`の場合にちょっと面倒\
  ただ、これはOS以前におかしいとは思ってる -> [Excelは組版じゃない](../excel-is-not-typesetting)
- 互換ソフトウェアは多いし、Webのoffice(365であれば)などを使えばファイル形式はそこまで問題はない
- ただ、2026年にExcelマクロとかが必要なこともあり、完全な互換は保証できない
- 3Dとかモデリング, ゲーム系は大変そう? (分野が違いすぎて無知)

所属大学は基本的にソフトウェアより高レイヤーな科目が多く、Windowsじゃないと動かない計測器などを扱ったリはしない。そして主なローカルで動くソフトウェアはMSのofficeなどだけで、それ以外のツールは比較的にLinuxも対応していたり、Webで動作することも多いのでそこまで茨の道ではない。

= 解決策

*WindowsをKVMなどで仮想化する*のが一番楽。適当にMSのサイトからwin11とかのisoを落としてきてvirt-managerあたりでセットアップすればそれなりに動く。
