- 句点の後のスペースは不要

## Typst風記法(remark-typstプラグイン)

- `*strong*` → 太字(従来の`**strong**`もそのまま使える)
- `_emphasis_` → 斜体
- `#footnote[内容]` → インライン脚注(自動採番。中でmarkdown記法も使える)。GFMの`[^1]`も併用可
- `#quote(attribution: "出典名", url: "https://...")[引用文]` → 出典付き引用(`<figure>`+`<blockquote>`+`<figcaption><cite>`)
  - 引数はどちらも任意。`url`のみなら出典表示はURL、`attribution`のみならリンクなし、`#quote[...]`(引数なし)はただの`<blockquote>`
  - `url`は`<blockquote cite="...">`にも入る
  - 行頭(ブロックの先頭)に書く。`[`と`]`の間は複数段落・リスト・コードブロックも書ける(`]`は独立行でよい)
  - `]`が見つからない場合は変換されずそのまま。引用文中の`[`/`]`は対応が取れていれば問題ない
  - 従来の`> `引用もそのまま使える
- 行頭の`=`が見出し(h1は記事タイトルなので`=`はh2から)。`##`等のATX見出しも併用可
  | typst | semantic |
  | --- | --- |
  | `= ` | h2 |
  | `== ` | h3 |
  | `=== ` | h4 |
  | `==== ` | h5 |
  | `===== ` | h6 |
  - マーカーの後にスペースが必要(`=見出し`は変換されない)
  - 見出しの前後には空行が必要。空行なしで本文に続けると段落の一部として扱われ変換されない
  - `======`(6個以上)は変換されない。リスト項目内(`- = x`)も対象外
- コードブロック・インラインコード内は変換されない
- GitHub等のプレビューでは`*x*`は斜体に見える点に注意
